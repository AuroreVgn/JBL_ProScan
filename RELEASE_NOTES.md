# JBL ProScan 1.0.0

First public release combining:

- the JBL ProScan Home Assistant custom integration;
- automatic myJBL authentication and basin selection;
- current water-analysis sensors and complete history;
- multilingual support: French, English, German, Spanish, Italian, Dutch and Portuguese;
- the JBL ProScan Lovelace card with visual editor, quality indicators and history chart;
- responsive support for Sections dashboards;
- visible integration and card versions.
